# veigh

Site especial do Veigh para o meu portfólio

## OBJETIVO

Desenvolver um site com HTML, CSS e JavaScript sobre o cantor e compositor Thiago Veigh, conhecido também somente como Veigh. Nesse projeto terá organizado o contéudo, o design, a programação e tudo que for necessário.

Esse projeto é uma forma de eu estudar e aprimorar meus conhecimentos com o Web Design e o Desenvolvimento Web. Além também de ser uma forma de agradecer por criar músicas tão animadas, motivacionais e intensas, do jeito que gosto de apreciar a música hoje em dia.
